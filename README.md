# ok-kes 卡厄思实验版

基于 ok-kes v1.4.10 的非官方实验版。

## 下载

请到 Releases 下载：

- `ok-kes_完整包_20261030.zip`
  完整程序 + Python 环境 + 实验版代码 + 配置
- `ok-kes_实验包_20261030.zip`
  仅实验版覆盖代码，需要已有 ok-kes v1.4.10

## 安装

完整包解压后运行 `ok-kes.exe`。

实验包解压后，在实验包目录执行：

`powershell -ExecutionPolicy Bypass -File .\install.ps1`

详细步骤见 [安装指南](安装指南.md)。
